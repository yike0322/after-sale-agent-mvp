# 优惠券核验规则（演示数据）

> 本文为虚构规则。所有金额、商品、账号均为演示数据。

## 判定优先级

1. 优惠券不存在、非本人、状态不是 `AVAILABLE`，或当前时间不在有效期内：不可用。
2. 订单金额低于 `threshold_amount`：不可用，返回 `COUPON_THRESHOLD_NOT_MET`。
3. 以上均通过：可用，并返回减免金额；不会真正改变订单金额。

## 可复现案例

| 订单 / 优惠券 | 预期结论 | Java 决策码 |
| --- | --- | --- |
| `O1001` / `C1001` | 订单 80.00，小于门槛 100.00 | `COUPON_THRESHOLD_NOT_MET` |
| `O1002` / `C1002` | 2026-08-13 后已过期 | `COUPON_EXPIRED` |

模型解释只拿到订单金额、门槛、优惠券状态和决策码，不拿账号、令牌或原始对话全文。
